## ✨ Featured Project

<div align="center">

### 🗣️ AI-Assisted Speech Therapy Platform

*AI-powered tools for speech, reading and writing practice.*

</div>

The platform combines multiple artificial intelligence and software technologies to analyze user exercises and provide interactive feedback.

### 🔍 Features

- 🎙️ Speech & pronunciation analysis
- 🔊 Audio feature extraction
- 🗣️ Speech-to-Text technologies
- 👁️ Handwriting analysis with OCR
- 🖼️ Image processing with OpenCV
- 📊 Progress tracking & performance analytics
- 🧠 AI-powered exercise evaluation
- 🏆 Challenges & leaderboard system
- 💬 Social interaction features
