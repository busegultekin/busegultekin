## ✨ Featured Project

### 🗣️ AI-Assisted Speech Therapy Platform

An intelligent web application designed to support speech, reading and writing practice through AI-powered analysis.

**Some technologies behind the project:**

`Python` • `FastAPI` • `React` • `OpenCV` • `Speech Recognition` • `Whisper` • `OCR` • `SQLite` • `Machine Learning`

**Highlights:**

* 🎙️ Speech & pronunciation analysis
* 👁️ Handwriting and image analysis with OCR
* 📊 Progress tracking and performance analytics
* 🧠 AI-powered exercise evaluation
* 🏆 Challenges, scoring and interactive learning
